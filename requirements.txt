# ---------------------------------------------------------------------------
# Requirements — NVIDIA valuation study (data pipeline + analysis)
# Python 3.10+  (tested on 3.12)
#
# One global file for the whole project. Two logical groups: the data pipeline
# under Source/, and the analysis notebooks (descriptive + diagnostic) that
# cover the six analytical pillars. The pipeline group alone rebuilds every
# dataset; the analysis group is what regenerates the figures.
#
# Module dependency map:
#   Source/sec_edgar_ingest.py     ->  pandas, requests
#   Source/yahoo_prices_ingest.py  ->  pandas, yfinance
#   Source/segments_ingest.py      ->  pandas
#   Source/join_quarterly.py       ->  pandas
#   descriptive analysis/*.ipynb   ->  pandas, numpy, matplotlib, scipy, ruptures
#   diagnostic  analysis/*.ipynb   ->  pandas, numpy, matplotlib, scipy, statsmodels, ruptures
#
# Pillar -> library:
#   P1 structural breaks  ->  ruptures (changepoints), statsmodels (break/Chow tests)
#   P2 peer divergence    ->  pandas (rolling corr), matplotlib, scipy (significance)
#   P3 revenue mix        ->  matplotlib (stacked area), pandas
#   P4 valuation decomp.  ->  matplotlib (waterfall/scatter), pandas
#   P5 margin expansion   ->  matplotlib, pandas
#   P6 capex linkage      ->  scipy / statsmodels (cross-corr lead-lag), matplotlib
#   diagnostic hypothesis tests (5 research Qs)  ->  scipy.stats, statsmodels
#
# Install:   pip install -r requirements.txt
# Lock:      pip freeze > requirements.lock      (exact reproducible pin)
# ---------------------------------------------------------------------------
